关键词 · 知识图谱 Knowledge Graph

点是“东西”，线是“关系”

普通网站像一本书，一页一页往下翻。知识图谱更像一张网：每个点是一个对象（一种癌、一个药、一个靶点），每条线写明它们是什么关系。

所以你可以从任何一点出发，顺着线走到所有相关的东西。

🏈 像战术板：每个球员一张卡，连线就是传球路线

AI 生成示意图

举个真实的例子

从一个癌种，走到一篇论文

示意图为课程自绘，简化了真实关系。在网站上，每个方框都是一页，点进去还能继续往外走。

每一页都分三层

先说人话，再说术语，最后给出处

第一层 · TL;DR

一两句大白话

新手也能看懂这是什么。“TL;DR”是英文网络用语，意思是“太长不看版”。

第二层 · 技术层

给专业读者

分型、机制、数据、标准治疗、在研管线。术语都有悬停解释。

第三层 · 来源

一手出处 + 核对日期

每条记录至少链接一个原始来源，写明最近一次核对是哪天。

读法：先看 TL;DR 判断要不要深读，重要的事一定回到原始来源核实

第四幕

让 AI 也能读这张地图

网页给人看，接口给机器读

04

关键词 · API 接口

像检验科的标准化报告单

网页是给人看的，排版好看但机器难读。API 是同一份数据的“标准格式版”，程序和 AI 可以直接读取、筛选、统计。

OnCo 的接口免费、不需要密钥；还专门给大模型准备了 llms.txt 和每个对象一份的 Markdown 说明。

🏈 API 就是统一格式的战术手语，任何球员一看就懂

# 在电脑终端运行（只需 Python 3） git clone https://github.com/TUANZIDING/onco-cc-guide cd onco-cc-guide python3 示例/检索示例v1.0.py sarcopenia # 输出：类型 + 名称 + 网页链接 [term] Sarcopenia https://onco.cc/terms/sarcopenia/

MCP（让 AI 助手直接调用 OnCo 的接口协议）官方已写好，但 2026-10-19 尚未发布到 npm，需要从源码构建。相关课：MCP 协议。

用之前，先记住五条

安全边界

01网站自己声明：仍在建设中，可能不完整、过时或有错。

02不是医学建议。临床决策回到原始来源和指南。

03“已获批”看国家：先在页眉选择国家，美国获批不等于中国获批。

04数据许可 CC BY-NC 4.0：教学和个人使用免费，须署名；商业使用要付费授权。

05把病例交给 AI 查资料时，先去掉病人隐私信息。
